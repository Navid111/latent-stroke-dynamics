## Smoke 1 execution

The 64/16/32, seed-11 CPU run completed without a traceback or reported memory pressure. Encoding was fast on the M1, the Hugging Face unauthenticated warning was harmless, and all expected artifacts were written.

The tiny-overfit diagnostic reduced balanced MSE from `0.0374769` to `0.0006982`, a 98.14% reduction. Both trainable models had finite, monotonically improving validation loss through epoch 8.

Validation selected the linear model. Its test action-region MSE was `0.001278`, compared with `0.002469` for identity and `0.002024` for mean delta. This corresponds to 48.2% and 36.8% aggregate improvements. Crowding-specific improvements were +67.7%, +6.3%, and −25.7% at 0, 5, and 15 prior strokes.

The run remained correctly labeled `diagnostic_only`.

## Review findings and corrections

### Duplicate counterfactual outcomes

The nominal retrieval result was 31.25%, but five of 32 rows showed exact true-versus-width score ties across every evaluated model. Therefore some nominal candidates were aliases, and the assumed 25% chance rate did not hold.

The corrected implementation now deterministically searches within each semantic counterfactual class until all four rendered outcomes differ from the current canvas and from one another. It also rejects exact aliases after feature encoding and versions the counterfactual cache.

### Formal-seed exposure

The smoke command inadvertently used prefixes from the originally reserved formal data seeds. Those seeds are now development-only. Before any formal run, Amendment 1 reserved untouched seeds `20260824`, `20260825`, `20260826`, and stress base `20260827`. Thresholds, models, loss, and metrics were not changed.

### Diagnostics and plots

The script now checks overfit success, finite outputs, candidate uniqueness, the exact model/canvas/seeds, and explicit `--formal-run` intent before permitting a gate decision. It also writes aggregate metrics by crowding, crowding and retrieval plots, validation curves, and a common-scale residual comparison.
