# 2026-08-22 — Stage 3 planner foundation

## Work completed

Implemented the first Stage 3 code layer after reading the frozen protocol and current repository instructions.

The new planning module separates target preprocessing, pixel metrics, candidate proposal, exact rendering, selection, and trajectory recording. Candidate generation follows the frozen 80/20 error-guided and uniform mixture, fixed palette and width choices, normalized length range, and exact candidate budget. Unchanged actions and duplicate rendered outcomes are rejected.

Random and exact-greedy planners now share the same deterministic proposal machinery. Every selected action is executed by the exact renderer. Optional frame capture stores the initial canvas and every resulting canvas without modifying the renderer.

## Tests added

2. deterministic, unique, changing candidates;
3. error-guided location sampling;
4. exact candidate selection;
5. deterministic trajectories and exact-versus-random ordering;
6. invalid metric input.
