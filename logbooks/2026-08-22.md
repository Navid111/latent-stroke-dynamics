## Painter packaging

Added a root `paint.py` command backed by a reusable package module. The command accepts an arbitrary Pillow-supported image, performs deterministic center-crop/grayscale preprocessing, and runs random, exact, or learned planning. It saves processed and final images, ordered stroke JSON, per-step and summary metrics, every frame, a GIF, a progress plot, a fixed-scale comparison, and full configuration metadata.

The learned path verifies the frozen checkpoint metadata and digest and never retrains. Completed and incomplete output directories are protected from overwrite. Three tests cover complete exact-mode artifact generation plus completed/incomplete output guards. Local validation is pending; the next expected suite result is 36 passing tests.
