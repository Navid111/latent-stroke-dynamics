# 2026-08-22 — Stage 3 smoke pass and learned-checkpoint workflow

## Random/exact smoke review

The first Stage 3 smoke passed its engineering purpose. Exact greedy reduced target MSE from `0.149447` to `0.074427` after 20 strokes, a 50.20% improvement. Random selection reached only `0.144913`, a 3.03% improvement. Exact improved all 20 actions and its deterministic replay passed.

The visual artifacts agree with the metrics. Exact planning captures the dominant target structures while random selection remains imprecise. Error panels use a fixed 0–255 scale and are directly comparable.

## Learned-planner implementation

Added a strict local checkpoint format for the 833-parameter pixel MLP. The checkpoint stores architecture, data seeds, training settings, selected validation epoch, and an integrity digest. Loading reconstructs the architecture, checks metadata and parameter count, and verifies weights.

Added a separate trainer using only the fixed 1,000 training and 200 validation transitions. It never generates paired test rows. The checkpoint is explicitly a Stage 3 deployment artifact and cannot replace the paired-control result.

Added memory-batched candidate prediction and the learned planning loop. Candidate ranking uses predicted full-canvas target MSE; the chosen stroke is executed exactly. Every step records exact rank, top-1/top-5 agreement, regret, and whether the true canvas improved.

Three tests cover checkpoint round-trip identity, oracle candidate scoring, and oracle end-to-end planning behavior. Local validation and checkpoint training are next.
