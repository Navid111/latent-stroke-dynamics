# 2026-08-21 — Gate 2 formal decision

## Pre-formal diagnosis

The development decomposition identified width discrimination as the main retrieval bottleneck. No implementation defect justified changing the frozen primary experiment.

## Formal run

The preregistered 1,000/200/300 run completed with three 100-example stress slices and model seeds `11`, `22`, and `33`. It reported `formal_run_requested: true` and `formal_eligible: true`. Validation selected the MLP family. All implementation sanity, finite-metric, candidate-uniqueness, and seed checks passed.

## Formal result

- selected MLP action-region MSE: 0.000860;
- identity action-region MSE: 0.002250;
- mean-delta action-region MSE: 0.002003;
- improvement versus identity: 61.8%;
- improvement versus mean delta: 57.1%;
- crowding improvements: +79.0%, +43.3%, and +25.0%;
- counterfactual retrieval: 27.7%.

The model passed both average-error margins, all crowding checks, and all sanity checks. It failed the required 50% counterfactual retrieval criterion. Since the protocol defines retrieval at or below 35% as fail, the formal Gate 2 decision is **fail**, not borderline.

## Visual review

The plots agreed with the tables. MLP overtook linear late in stable validation training; there was no seed collapse. The residual prediction localized the shallow diagonal stroke but underestimated its magnitude and spatial extent. The crowding plot’s 30% line is potentially misleading because that threshold applied in aggregate, while individual crowding slices required positive improvement only.

## Formal retrieval decomposition

The multi-seed-aware diagnostic passed in the complete 19-test suite. MLP retrieval was stable at 26.3%, 27.3%, and 29.3% across seeds. Width-changed outcomes were selected 48.2% of the time.

Pairwise true-outcome win rates were:

- versus shifted position: 77.9%;
- versus changed width: 40.7%;
- versus changed intensity: 75.2%.

The model is action-sensitive but insufficiently precise about stroke width. The formal width result was effectively unchanged from development despite more data, while position, intensity, and average-error behavior improved.

## Decision and next step

Do not rerun or tune the latent formal experiment. The result is now fully archived and diagnosed. The next experiment is the preregistered minimal pixel-space action-conditioned control; Gate 3 planning remains blocked.
