## Pixel-control protocol freeze

The required explanatory pixel-space control was specified and frozen before implementation. It reuses the paired Gate 2 transition splits but predicts normalized 64×64 pixel residuals using full-resolution current pixels, the same seven-value action vector, an exact proposed-stroke mask, and pixel coordinates.

Frozen learned models are a shared affine map and a tiny `11 -> 64 -> 1` MLP with model seeds `11`, `22`, and `33`. Identity, training mean delta, and an exact compositing oracle remain visible. Training uses balanced inside/outside residual MSE. Four-way pixel retrieval uses the same unique counterfactual outcomes and the same 50% explanatory standard.

This control is explicitly post-Gate-2 and cannot revise the latent fail. A successful pixel result would localize the problem to the overall latent patch formulation; another retrieval failure would implicate deterministic average-error prediction more generally.
