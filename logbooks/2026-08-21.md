# 2026-08-21 — Stage 3 scope reopened

## Correction

The experimental feasibility core was complete, but the project’s requested final image-to-strokes artifact was not. With a 24 September deadline and approximately 34 days remaining, stopping after the pixel control would be premature.

The user explicitly confirmed that the desired deliverable is a program that accepts an image and paints it line by line. Stage 3 was therefore reopened in a constrained pixel-space form.

## Scientific basis for the pivot

The learned latent predictor remains unsuitable for planning because it formally failed exact-action retrieval. The paired pixel predictor achieved 100% retrieval and provides a justified alternative transition model. The final artifact will compare random selection, exact-renderer greedy pixel planning, and learned pixel-predictor planning.

The selected action will always be executed with the exact renderer. This preserves the world-model loop: propose, predict, rank, execute, observe, and repeat.

## Frozen Stage 3 scope

- 64×64 grayscale target preprocessing;
- straight-line strokes;
- 128 candidates and 100 selected strokes per run;
- six fixed renderer-generated targets for quantitative comparison;
- random, exact greedy, and learned pixel methods;
- candidate proposal guided by the current target error with uniform exploration;
- separate demonstration checkpoint trained from train/validation data only;
- user-image CLI and animation output;
- no latent planner, reinforcement learning, color, or multi-step search.

Implementation begins with preprocessing, candidates, and exact planning tests.
