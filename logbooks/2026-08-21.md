The failure is not uniform across action properties. Linear pairwise true-outcome win rates were:

- versus shifted position: 66.7%;
- versus changed width: 46.9%;

The model selected the width-changed candidate on 37.5% of examples. Together with the shared-scale heatmap, this supports a smooth or under-amplitude residual interpretation rather than complete action blindness.

Width is already encoded explicitly and through fractional mask coverage, all candidates are unique, and the implementation checks pass. No implementation repair is justified before formal evaluation.
